# Grass Kernel — USB Mass Storage for Samsung Galaxy A51

A modified version of **Grass Kernel** for the Samsung Galaxy A51, featuring USB Mass Storage support.

## 📱 Device Support

- **Device:** Samsung Galaxy A51
- **Android:** 13
- **Binary:** 8
- **Codename:** A51
- **Platform:** Samsung Exynos 9611
- **Architecture:** ARM64
- **Kernel:** Grass Kernel
- **Toolchain:** Clang / LLVM

## ✨ Features

- USB Mass Storage support
- Based on Grass Kernel
- Built for Samsung Galaxy A51
- Clang/LLVM compiled

## 🔌 USB Mass Storage

This kernel includes USB Mass Storage functionality, allowing supported USB storage configurations to be exposed to a connected computer as a mass storage device.

**Note:** USB Mass Storage availability and behavior depend on the device configuration, Android version, USB implementation, and compatible userspace tools.
